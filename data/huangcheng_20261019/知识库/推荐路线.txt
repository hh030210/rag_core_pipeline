## 游览路线推荐【一】
御书楼 → 石牌坊 → 大学士第 → 小姐院 → 西花园 → 望河亭 → 中道庄城楼
→西南角楼 → 步步高台阶 → 文昌阁 → 南堞楼 → 藏兵洞 → 中华字典博物馆
→麒麟院 → 河山楼 → 容山公府 → 御史府 (生铁冶铸技艺展览馆) → 陈氏宗祠
→世德院 → 吟翠廊 → 悟因楼 → 南书院 → 状元桥 → 魁星阁 → 碑廊
→流杯亭 → 小南门 → 陈廷敬纪念馆 → 北门出口 → 明清商业文化街 → 紫芸阡 → 西山院
温馨提示：
1. 纯参观时长约 120 分钟；
