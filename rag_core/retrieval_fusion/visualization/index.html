景区检索与融合对比

语义、维度与融合检索结果对比；点击 chunk 编号查看正文。

线上融合基准

语义、维度两路各自在本路候选内做 Min–Max 归一化：N(s) = (s − min(s)) / (max(s) − min(s))；若本路分数相同，则该路候选归一化分均为 1。按 chunk 并集计算：Fonline = (1 − α)Nsem + αNdim，缺失路贡献为 0。

参数：α 是维度路权重，当前默认 α = 0.20（语义 0.80、维度 0.20，可由 DIM_ALPHA 配置）。本页“线上融合”列展示快照里已保存的实际排名；历史快照含不同分支，不在页面重算。

离线融合：维度分数融合

对线上融合候选重排：Foffline = S* + 0.05Dnorm + 0.10Lnorm。S* 为语义原始分；缺失时用 max(0, min(S) − 0.025) 估计。Dnorm 为维度路 Min–Max 分（缺失为 0）；Lnorm 为 IDF 加权字符 2/3/4-gram 查询覆盖率，再除以当前候选池的最高词面分。

参数：维度权重 0.05、词面权重 0.10、语义缺失惩罚 0.025，均固定用于离线基准；IDF 按当前候选池文档频率计算，文本最多取前 4000 字。可在上方条形图中选择该策略查看命中统计。

推荐融合：维度角色校准

从原始语义分、维度分和词面证据起算：Frec = Seff + 0.15Isem(Srank − Seff) + sD·0.0375Deff + sL·0.075[(1 − 0.75)L + 0.75W] + 0.015IroleA。

校准：满足“两路首位相同，且至少一路 Top-5 有 ≥3 个候选、相对 gap ≥2%、突出程度 ≥5”时 β=0.625，否则 β=0；其中相对 gap=(Top1−Top2)/max(|Top2|, 10−8)，突出程度=gap/(Top2 至 Top-5 尾部的平均相邻分差)。Seff 是语义原分与语义线性名次分按 β 混合（未召回语义用 max(0, 本路最低分)，不加名次分）；Deff 是归一化维度分与维度线性名次分按 β 混合。W 是 320 字窗口、160 字步长的局部 IDF 覆盖；A 是查询事实锚点的 IDF 覆盖。窗口、锚点分均在候选池内归一化。

角色参数：仅当约束全属于 entity_name / geo_admin / geo_position、没有具体 POI 且语义相对 gap ≥1% 时，Irole=1，sD=0.85×0.25=0.2125、sL=0.5；否则 Irole=0、sD=0.85、sL=1。事实锚点权重 0.015；语义名次混合 0.15；词面局部窗口替换比例 0.75。配置固定在 recommended.py，Gold 仅用于离线评估。

融合策略与 Top-K 仅影响下方条形图；按已有快照排名统计。
